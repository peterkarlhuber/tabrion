# Support

Tabrion is an open-source project maintained in spare time. There is no commercial support and no guaranteed
response time.

* **Questions and problems:** first check the [documentation](docs/index.md). If that does not help, open an issue
  with the "Bug report" or "Feature request" template.
* **Security issues:** never in public issues; see [SECURITY.md](SECURITY.md).
* **Problems in SQLite, PostgreSQL, psycopg, SQLAlchemy or Alembic:** report them to those projects.

When you report a problem, include the Tabrion version or commit, the Python version, the database and its
version, `pip show psycopg sqlalchemy alembic`, a minimal script and the full exception. Remove passwords,
connection strings and data values first.
